📌 1. Definisi Formal Turunan dari Limit Selisih Beda

Turunan (Derivatif) dari fungsi f(x) pada titik x didefinisikan secara formal sebagai limit dari rasio selisih beda ketika interval h mendekati nol:

f'(x) = dy/dx = limh → 0 [f(x + h) - f(x)] / h
  • Makna Geometris: Nilai f'(c) menyatakan gradien (kemiringan m) dari garis singgung kurva y = f(x) tepat pada titik singgung (c, f(c)).
  • Makna Fisis: Menyatakan laju perubahan nilai sesaat (instantaneous rate of change).

📌 3. Aturan Perkalian & Pembagian Fungsi

A. Aturan Hasil Kali Dua Fungsi (Product Rule):
Jika y = u · v di mana u = u(x) dan v = v(x), maka:
y' = (u · v)' = u' · v + u · v'

Contoh Kasus: Tentukan turunan dari y = (2x + 1)(x² - 3).
1. Tentukan u = 2x + 1 → u' = 2.
2. Tentukan v = x² - 3 → v' = 2x.
3. Masukkan rumus: y' = 2(x² - 3) + (2x + 1)(2x) = 2x² - 6 + 4x² + 2x = 6x² + 2x - 6.

B. Aturan Hasil Bagi Dua Fungsi (Quotient Rule):
Jika y = u / v dengan v(x) ≠ 0, maka:
y' = (u / v)' = (u' · v - u · v') / v²

Contoh Kasus: Tentukan turunan dari y = (3x - 2) / (x + 1).
1. Tentukan u = 3x - 2 → u' = 3.
2. Tentukan v = x + 1 → v' = 1.
3. Masukkan rumus:
y' = [3(x + 1) - (3x - 2)(1)] / (x + 1)² = [3x + 3 - 3x + 2] / (x + 1)² = 5 / (x + 1)².

📌 4. Aplikasi: Persamaan Garis Singgung Kurva

Untuk mencari persamaan garis singgung kurva y = f(x) pada titik berabsis x = x₁:

  1. Hitung ordinat titik singgung: y₁ = f(x₁).
  2. Hitung gradien kemiringan garis singgung dengan turunan pertama: m = f'(x₁).
  3. Gunakan rumus persamaan garis melalui satu titik: y - y₁ = m · (x - x₁).

Contoh: Tentukan persamaan garis singgung kurva y = x² - 4x + 3 di titik x = 3.
1. Nilai y₁: y₁ = 3² - 4(3) + 3 = 9 - 12 + 3 = 0. Titik singgung adalah (3, 0).
2. Turunan kurva: y' = 2x - 4.
3. Gradien m pada x = 3: m = 2(3) - 4 = 6 - 4 = 2.
4. Persamaan garis singgung: y - 0 = 2(x - 3) → y = 2x - 6.

💡 BAGIAN 2: PENGAYAAN MATERI FIRST PRINCIPLES, INDUSTRI & JEBAKAN UTS

  • Tanda Operasi Pembagian: Ingat rumus turunan pembagian WAJIB bertanda KURANG (u'v - uv'), bukan tambah! Tertukar tanda adalah penyebab kesalahan terbanyak saat ujian.
  • Turunan Bentuk Akar: Bentuk √x dapat diubah menjadi pangkat pecahan x^(1/2). Turunannya adalah (1/2)x^(-1/2) = 1 / (2√x).
  • Penerapan Optimasi di SI: Titik stasioner diperoleh ketika turunan pertama bernilai nol: f'(x) = 0. Konsep ini digunakan dalam algoritma Gradient Descent pada machine learning untuk meminimalkan loss function.
