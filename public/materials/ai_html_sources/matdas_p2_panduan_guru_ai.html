BAB 1. The Big Picture: Konsep Relasi Urutan & Pembalikan Tanda

Berbeda dengan persamaan yang menghasilkan titik solusi diskrit (misal: x = 5), Pertidaksamaan menghasilkan rentang solusi kontinu tak hingga yang disebut Himpunan Penyelesaian (HP). Pertidaksamaan adalah model dasar batas kapasitas (capacity constraint) dalam riset operasional dan arsitektur sistem.

🚨 HUKUM MUTLAK PERTIDAKSAMAAN:
Jika kedua ruas dikalikan atau dibagi dengan bilangan negatif, arah tanda pertidaksamaan WAJIB DIBALIK!
Contoh: -2x < 6 ⇒ kedua ruas dibagi -2 ⇒ x > -3 (tanda < berbalik menjadi >).
BAB 2. Lima Langkah Baku Menentukan Himpunan Penyelesaian (Metode Anti-Gagal)

Untuk menyelesaikan sembarang pertidaksamaan aljabar kuadrat maupun pecahan rasional, gunakan 5 tahapan baku berikut:

Langkah ke- Tahapan Baku Penentuan HP Tindakan Operasi Aljabar Ketentuan Kritis & Larangan Keras (✗)
1 Nolkan Ruas Kanan Pindahkan semua suku ke ruas kiri sehingga bentuk persamaan menjadi f(x) < 0 atau f(x) > 0. DILARANG KERAS mengalikan silang penyebut yang mengandung variabel karena tandanya belum tentu positif!
2 Faktorisasi / Samakan Penyebut Ubah bentuk polinomial ke faktor linier (x - x₁) (x - x₂). Untuk pecahan, satukan menjadi P(x) / Q(x). Pastikan koefisien suku utama bertanda positif untuk mempermudah uji tanda nantinya.
3 Tentukan Titik Pemecah (Split Points) Cari pembuat nol pembilang (P(x) = 0) dan pembuat nol penyebut (Q(x) = 0). Titik pembuat nol dari penyebut SELALU lingkaran kosong (○) karena pembagian dengan nol mustahil!
4 Plot Garis Bilangan & Uji Tanda Petakan semua titik pemecah pada garis bilangan berurut dari kecil ke besar, lalu pilih satu angka uji (misal: x = 0). Evaluasi tanda (+ / -) di setiap daerah interval. Tanda berubah berselang-seling kecuali jika ada faktor berpangkat genap.
5 Himpunan Penyelesaian (HP) Jika pertidaksamaan bertanda > 0 atau ≥ 0, pilih daerah (+). Jika bertanda < 0 atau ≤ 0, pilih daerah (-). Tuliskan notasi himpunan matematika formal dan notasi selang (interval) secara presisi.
BAB 3. Pembahasan Step-by-Step Latihan Soal Slide Dosen
Kasus 1: Pertidaksamaan Kuadrat
Soal: x2 - x < 6 
1. Nolkan ruas kanan:
   x2 - x - 6 < 0
2. Faktorkan:
   (x - 3)(x + 2) < 0
3. Titik pemecah:
   x = 3 dan x = -2 (keduanya lingkaran kosong ○)
4. Uji titik x = 0:
   (0 - 3)(0 + 2) = -6 (Tanda Negatif -)
5. Garis Bilangan:
   (+) --- (-2) --- (-) --- (3) --- (+)
6. Karena diminta < 0, ambil interval negatif (-):
   HP = { x ∈ ℝ | -2 < x < 3 } = ( -2, 3 )
Kasus 2: Pecahan Rasional
Soal: (x - 1) / (x + 2) ≥ 0 
1. Ruas kanan sudah nol: (x - 1) / (x + 2) ≥ 0
2. Titik pemecah pembilang:
   x - 1 = 0 ⇒ x = 1 (lingkaran PENUH • karena tanda ≥)
3. Titik pemecah penyebut (Syarat Q(x) ≠ 0):
   x + 2 = 0 ⇒ x = -2 (lingkaran KOSONG ○)
4. Uji titik x = 0:
   (0 - 1) / (0 + 2) = -1/2 (Tanda Negatif -)
5. Garis Bilangan:
   (+) --- (-2) --- (-) --- [1] --- (+)
6. Karena diminta ≥ 0, ambil interval positif (+):
   HP = ( -∞, -2 ) ∪ [ 1, ∞ )
BAB 4. Kesalahan Fatal Mahasiswa yang Sering Menggugurkan Nilai UTS
⚠️ Dilarang Keras Perkalian Silang Pecahan Mengandung Variabel!
Banyak mahasiswa menulis: (x - 1) / (x + 2) ≥ 0 ⇒ x - 1 ≥ 0 × (x + 2) ⇒ x ≥ 1. Ini adalah SALAH FATAL karena nilai (x + 2) bisa bernilai negatif (yang membalik tanda pertidaksamaan). Jika dikalikan silang, daerah penyelesaian x < -2 hilang seketika dan nilai soal langsung 0!
