📌 1. Karakteristik & Batasan Struktur CASE-OF

Struktur CASE-OF adalah struktur percabangan yang digunakan untuk memilih satu aksi dari sekumpulan alternatif berdasarkan pencocokan nilai suatu ekspresi pemilih (selector):

  • Syarat Mutlak Variabel Pemilih: Tipe data variabel pemilih WAJIB BERTIPE ORDINAL (tipe data yang urutan elemennya pasti dan dapat dihitung: integer, char, boolean, atau enumerasi).
  • Larangan Keras: Tipe data real (pecahan berkoma) dan string DILARANG dijadikan variabel pemilih dalam CASE-OF standar.
  • Keunggulan: Struktur kode jauh lebih rapi, terhindar dari indentasi tangga yang terlalu dalam, serta waktu kompilasi yang efisien.

📌 2. Sintaks Formal & Ragam Format Selector CASE-OF 

case variabel_pemilih of
  nilai_tunggal : aksi_1;
  nilai_a, nilai_b : aksi_2;         { Daftar nilai jamak dipisah koma }
  nilai_awal..nilai_akhir : aksi_3;  { Menggunakan rentang subrange (..) }
else
  aksi_default;                      { Dikerjakan bila tidak ada nilai yang cocok }
end;

Contoh Format Nilai Pemilih:

  • Nilai tunggal integer: 1: writeln('Hari Senin');
  • Nilai jamak karakter char: 'y', 'Y': writeln('Anda menyetujui syarat.');
  • Rentang subjangkauan (subrange): 80..100: writeln('Grade A');

📌 3. Program Lengkap: Menu Pembelian & Kasir Interaktif 

program MenuResto;
uses crt;

var
  pilihan, jumlah: integer;
  harga, total: real;
  nama_menu: string[30];

begin
  clrscr;
  writeln('========================================');
  writeln('       DAFTAR MENU KANTIN MAHASISWA     ');
  writeln('========================================');
  writeln('1. Paket Nasi Ayam Geprek  (Rp 15.000)  ');
  writeln('2. Paket Nasi Soto Ayam    (Rp 12.000)  ');
  writeln('3. Mie Goreng Spesial      (Rp 10.000)  ');
  writeln('4. Es Teh Manis Jumbo      (Rp  4.000)  ');
  writeln('========================================');
  write('Pilih Nomor Menu [1-4] : '); readln(pilihan);

  case pilihan of
    1: begin
         nama_menu := 'Paket Nasi Ayam Geprek';
         harga := 15000;
       end;
    2: begin
         nama_menu := 'Paket Nasi Soto Ayam';
         harga := 12000;
       end;
    3: begin
         nama_menu := 'Mie Goreng Spesial';
         harga := 10000;
       end;
    4: begin
         nama_menu := 'Es Teh Manis Jumbo';
         harga := 4000;
       end;
  else
    begin
      writeln('Nomor menu tidak terdaftar!');
      readln;
      exit; { Keluar dari program }
    end;
  end;

  write('Jumlah Porsi yang Dipesan : '); readln(jumlah);
  total := harga * jumlah;

  writeln('----------------------------------------');
  writeln('Pesanan Anda  : ', nama_menu);
  writeln('Harga Satuan  : Rp ', harga:0:0);
  writeln('Jumlah Porsi  : ', jumlah);
  writeln('Total Tagihan : Rp ', total:0:0);
  writeln('========================================');
  writeln('Terima kasih atas pesanan Anda!');
  readln;
end.

💡 BAGIAN 2: PENGAYAAN MATERI FIRST PRINCIPLES, INDUSTRI & JEBAKAN UTS

  • Perbedaan IF vs CASE-OF: Gunakan if-then-else jika kondisi melibatkan perbandingan relasional kompleks dengan variabel bertipe real/string (misal: ipk ≥ 3.50). Gunakan case-of jika pemilih berupa pilihan diskrit ordinal (menu 1-4, karakter pilihan Y/N).
  • Penutup Struktur CASE: Seluruh blok case ... of ditutup dengan kata kunci end; (tanpa membutuhkan begin di awal case).
  • Rentang Char: Pada Free Pascal, selector char mendukung subrange alfabet: 'a'..'z': writeln('Huruf kecil');.
