📌 1. Konsep Pemilihan Majemuk (Banyak Kasus)

Pemilihan Majemuk digunakan ketika persoalan memiliki tiga alternatif pilihan atau lebih. Struktur ini dibentuk dengan menggabungkan instruksi if di dalam bagian else dari instruksi sebelumnya:

{ Pola Pemilihan Majemuk Bertingkat }
if (kondisi_1) then
    aksi_1
else if (kondisi_2) then
    aksi_2
else if (kondisi_3) then
    aksi_3
else
    aksi_default  { penanganan kondisi fallback / nilai default }
endif
  • Mekanisme Evaluasi: Kondisi diuji secara berurutan dari atas ke bawah. Begitu salah satu kondisi bernilai TRUE, aksinya langsung dieksekusi dan seluruh cabang di bawahnya dilewati (tidak diuji lagi).

📌 2. Studi Kasus Konversi Grade Nilai Akademik

Mengonversi nilai angka mahasiswa (0 – 100) menjadi indeks huruf mutu berdasarkan standar akademik Unindra:

{ Algoritma Konversi Grade Nilai }
input(nilai)
if (nilai ≥ 80) then
    grade ← 'A'
else if (nilai ≥ 70) then
    grade ← 'B'
else if (nilai ≥ 60) then
    grade ← 'C'
else if (nilai ≥ 50) then
    grade ← 'D'
else
    grade ← 'E'
endif
output("Grade Mutu: ", grade)

Catatan Kritis: Perhatikan bahwa pada else if (nilai ≥ 70) tidak perlu lagi ditulis and (nilai < 80), karena nilai yang mencapai 80 ke atas sudah tersaring dan dieksekusi pada cabang pertama.

📌 3. Percabangan Bersarang (Nested IF)

Nested IF adalah struktur di mana di dalam blok aksi suatu pernyataan if terdapat struktur if lainnya. Sangat berguna untuk pengujian bersyarat bertingkat (misal: syarat golongan kerja dan status pernikahan):

if (golongan = "III") then
    gaji_pokok ← 4000000
    if (status_nikah = "Y") then
        tunjangan ← 500000
    else
        tunjangan ← 0
    endif
else
    gaji_pokok ← 3000000
    tunjangan ← 0
endif
total_gaji ← gaji_pokok + tunjangan

💡 BAGIAN 2: PENGAYAAN MATERI FIRST PRINCIPLES, INDUSTRI & JEBAKAN UTS

  • Anti-Redundansi: Menulis if (x ≥ 70 and x < 80) pada blok else if adalah pemborosan evaluasi logika jika cabang atas sudah menyaring x ≥ 80.
  • Jebakan Kasus Overlap: Pastikan urutan kondisi tersusun logis dari angka tertinggi ke terendah saat menggunakan operator ≥. Jika dibalik (misal if (x ≥ 50) di awal), maka nilai 90 akan salah didiagnosis masuk ke grade D!
  • Kompilasi Mesin: Struktur IF bertingkat yang teratur dapat dioptimasi oleh compiler menjadi instruksi jump table assembly berkecepatan tinggi.
