BAB 1. The Big Picture: Anatomy of Technical Procedural Documentation

Technical procedures in computer science—such as API specifications, deployment guides, user manuals, and algorithm walkthroughs—require absolute precision, unambiguous directives, and strict logical sequencing. A professional procedure document consists of four sections:

  1. Goal / Objective: What problem the procedure solves (e.g., "How to Configure HTTPS Reverse Proxy with Nginx").
  2. Prerequisites / Requirements: Software dependencies, hardware configurations, access tokens.
  3. Step-by-Step Instructions: Action-oriented steps driven by imperative verbs and transition markers.
  4. Verification / Validation: How to confirm the system is running correctly.
BAB 2. Grammar Engine: Imperative Sentences & Action Verbs

Imperative sentences omit the subject You and start directly with the base form of the verb (Infinitive without 'to'):

Command Type Syntactic Structure Technical Computing Example Purpose & Intent
Direct Action (+) Base Verb (V1) + Object "Initialize the Git repository before committing files." Mandatory operation to execute.
Prohibition (-) Do not / Don't + V1 "Do not commit API secret keys or credentials to public repositories." Prevent critical security or architectural failure.
Conditional Action If [condition], + Imperative "If the database port 5432 is blocked, verify your firewall rules." Conditional troubleshooting branch.
BAB 3. Sequence Markers & Step-by-Step Algorithm Walkthrough

To ensure clarity, technical writers use chronological transitional signposts:

Phase in Execution Transition Signals Example in Binary Search Algorithm
Initiation First, Initially, To begin with "First, sort the array in ascending numerical order."
Continuation Next, Subsequently, Afterward, Then "Next, calculate the midpoint pointer using mid = (low + high) / 2."
Conditioning Meanwhile, At the same time, Simultaneously "Compare the search target against the element at the midpoint index."
Termination Finally, Lastly, In conclusion "Finally, return the target index if found, or terminate with -1."
