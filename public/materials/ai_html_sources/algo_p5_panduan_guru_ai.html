📌 1. Konsep Dasar Struktur Pemilihan (Selection)

Struktur Pemilihan (Selection Control Structure) adalah struktur kontrol algoritma yang digunakan untuk mengevaluasi suatu kondisi logika (ekspresi Boolean) guna menentukan jalur instruksi mana yang akan dieksekusi selanjutnya oleh sistem.

  • Ekspresi Kondisi: Pernyataan relasional yang selalu menghasilkan nilai bertipe Boolean: TRUE (Benar) atau FALSE (Salah).
  • Operator Relasional: = (sama dengan), ≠ (tidak sama dengan), < (kurang dari), > (lebih dari), ≤ (kurang dari atau sama dengan), ≥ (lebih dari atau sama dengan).
  • Simbol Flowchart: Direpresentasikan oleh simbol belah ketupat (Decision Diamond) dengan satu jalur panah masuk dan dua jalur panah keluar bertanda label Ya (True) dan Tidak (False).

📌 2. Pemilihan Satu Kasus (Struktur IF-THEN)

Pada struktur satu kasus, instruksi hanya akan dikerjakan jika kondisi yang diuji terpenuhi (bernilai TRUE). Jika kondisi tidak terpenuhi (FALSE), instruksi tersebut dilewati dan alur berlanjut ke baris berikutnya:

{ Notasi Pseudocode Pemilihan Satu Kasus }
if (kondisi) then
    aksi_instruksi
endif

Contoh Studi Kasus: Menentukan diskon belanja pelanggan jika total belanja minimal Rp 100.000.

diskon ← 0
if (total_belanja ≥ 100000) then
    diskon ← 0.10 * total_belanja
endif
total_bayar ← total_belanja - diskon

📌 3. Pemilihan Dua Kasus (Struktur IF-THEN-ELSE)

Pada struktur dua kasus, terdapat dua alternatif tindakan yang saling menegasikan (komplementer). Jika kondisi bernilai TRUE maka aksi-1 dieksekusi; namun jika bernilai FALSE maka aksi-2 yang akan dieksekusi:

{ Notasi Pseudocode Pemilihan Dua Kasus }
if (kondisi) then
    aksi_1   { dikerjakan jika kondisi bernilai TRUE }
else
    aksi_2   { dikerjakan jika kondisi bernilai FALSE }
endif

Contoh Studi Kasus: Menentukan bilangan bulat genap atau ganjil menggunakan operator modulus.

if (bilangan mod 2 = 0) then
    output("Bilangan Genap")
else
    output("Bilangan Ganjil")
endif

💡 BAGIAN 2: PENGAYAAN MATERI FIRST PRINCIPLES, INDUSTRI & JEBAKAN UTS

  • Prinsip First Principles: Struktur percabangan mengubah alur eksekusi komputasi dari sekuensial linear menjadi graph terarah (directed acyclic graph).
  • Jebakan UTS: Pada penulisan pseudocode baku ANSI, setiap blok if wajib ditutup dengan endif agar cakupan aksi memiliki batasan yang tegas.
  • Optimasi Logika: Kondisi yang paling sering bernilai TRUE sebaiknya diuji terlebih dahulu untuk meminimalkan beban evaluasi siklus instruksi CPU.
