📌 1. Sintaks Baku IF-THEN-ELSE IF dalam Bahasa Pascal

Dalam bahasa pemrograman Pascal (Free Pascal / Turbo Pascal), percabangan majemuk memiliki aturan tata bahasa yang sangat presisi dan ketat:

if (kondisi_1) then
  pernyataan_1
else if (kondisi_2) then
  pernyataan_2
else if (kondisi_3) then
  pernyataan_3
else
  pernyataan_default;
⚠️ HUKUM MUTLAK PASCAL: Dilarang keras mengetik tanda titik koma (;) tepat sebelum kata kunci else! Tanda titik koma dianggap oleh kompilator sebagai akhir dari seluruh pernyataan IF, sehingga bila kata else ditemukan setelahnya, kompilator akan memunculkan galat sintaks fatal: Fatal: Syntax error, ";" unexpected but "ELSE" found.

📌 2. Compound Statement (Blok begin ... end;)

Bila suatu cabang keputusan memuat lebih dari satu instruksi, seluruh baris instruksi tersebut WAJIB dikelompokkan ke dalam blok majemuk menggunakan kata kunci begin dan diakhiri dengan end:

if (nilai ≥ 60) then
begin
  status := 'LULUS';
  keterangan := 'Selamat, pertahankan prestasi Anda!';
end  { <-- PERHATIKAN: Tidak ada titik koma sebelum kata else! }
else
begin
  status := 'GAGAL';
  keterangan := 'Mohon belajar lebih giat untuk semester depan.';
end; { <-- Titik koma diletakkan di akhir seluruh struktur }

📌 3. Program Lengkap: Perhitungan Nilai Akhir & Grade Mahasiswa

Implementasi studi kasus nyata sesuai berkas modul kuliah perkuliahan Unindra (Bobot: Tugas 20%, UTS 30%, UAS 50%):

program HitungNilaiAkhir;
uses crt;

var
  nama: string[30];
  tugas, uts, uas, na: real;
  grade: char;
  status: string[10];

begin
  clrscr;
  writeln('========================================');
  writeln('   SISTEM PENILAIAN AKADEMIK MAHASISWA  ');
  writeln('========================================');
  write('Masukkan Nama Mahasiswa : '); readln(nama);
  write('Masukkan Nilai Tugas    : '); readln(tugas);
  write('Masukkan Nilai UTS      : '); readln(uts);
  write('Masukkan Nilai UAS      : '); readln(uas);

  { Rumus Bobot Nilai Akhir }
  na := (0.20 * tugas) + (0.30 * uts) + (0.50 * uas);

  { Penentuan Grade Mutu }
  if (na ≥ 80) then
    grade := 'A'
  else if (na ≥ 70) then
    grade := 'B'
  else if (na ≥ 60) then
    grade := 'C'
  else if (na ≥ 50) then
    grade := 'D'
  else
    grade := 'E';

  { Penentuan Status Kelulusan }
  if (na ≥ 60) then
    status := 'LULUS'
  else
    status := 'TIDAK LULUS';

  writeln('----------------------------------------');
  writeln('Nama Mahasiswa : ', nama);
  writeln('Nilai Akhir    : ', na:0:2);
  writeln('Grade Mutu     : ', grade);
  writeln('Status Akhir   : ', status);
  writeln('========================================');
  readln; { Menahan jendela layar konsol }
end.

💡 BAGIAN 2: PENGAYAAN MATERI FIRST PRINCIPLES, INDUSTRI & JEBAKAN UTS

  • Kaidah Pemformatan Real: Sintaks na:0:2 membulatkan angka pecahan desimal agar tercetak rapi dengan tepat dua angka di belakang koma (misal: 82.50 bukannya format saintifik 8.2500000000E+01).
  • Tipe Data Grade: Menggunakan tipe data char untuk grade (karena hanya satu karakter 'A' s.d. 'E') jauh lebih hemat memori dibanding string.
  • Penanganan Input Nilai: Dalam Free Pascal, jika pengguna mengetik huruf pada input variabel real, program akan menghasilkan Runtime error 106 (Invalid numeric format).
