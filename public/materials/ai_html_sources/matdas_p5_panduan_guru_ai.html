🎙️ BAGIAN 1: KONSEP DASAR, SIFAT TEOREMA & FORMULA RESMI

Uraian materi dasar berdasarkan Slide 2 - 7 dokumen resmi perkuliahan FTIK Unindra.

📌 1. Definisi Formal & Konsep Intuitif Limit (Slide 2)

Pernyataan limx → c f(x) = L berarti bahwa bilamana nilai x bergerak mendekati c tetapi berlainan dari c (x ≠ c), maka nilai f(x) mendekati bilangan riil L.

Kasus Kritis Dosen: Mengapa Muncul Bentuk 0 / 0?
Tinjau fungsi f(x) = (x² - 1) / (x - 1).
Jika kita langsung memasukkan x = 1, maka:
f(1) = (1² - 1) / (1 - 1) = 0 / 0 (Tak Terdefinisi / Tanpa Arti)
Namun, dengan konsep limit, kita mencari apa yang terjadi saat x mendekati 1:
limx → 1 [(x - 1)(x + 1)] / (x - 1) = limx → 1 (x + 1) = 1 + 1 = 2
Kesimpulan: Fungsi tidak terdefinisi di titik x = 1, namun nilai limitnya ada dan bernilai 2!

📌 2. Sembilan Sifat Dasar Teorema Limit & Contoh Soal (Slide 3)

  1. limx → c k = k (Limit konstanta adalah konstanta itu sendiri)
  2. limx → c x = c (Limit fungsi identitas)
  3. limx → c [k · f(x)] = k · limx → c f(x) (Konstanta dapat ditarik ke depan limit)
  4. limx → c [f(x) + g(x)] = lim f(x) + lim g(x) (Penjumlahan limit)
  5. limx → c [f(x) - g(x)] = lim f(x) - lim g(x) (Pengurangan limit)
  6. limx → c [f(x) · g(x)] = lim f(x) · lim g(x) (Perkalian limit)
  7. limx → c [f(x) / g(x)] = lim f(x) / lim g(x), asalkan lim g(x) ≠ 0
  8. limx → c [f(x)]ⁿ = [lim f(x)]ⁿ (Perpangkatan limit)
  9. limx → c ⁿ√f(x) = ⁿ√[lim f(x)], asalkan lim f(x) > 0 untuk n genap
Contoh Soal a (Slide 3): limx → 4 (3x² - 2x)
Langkah Pengerjaan:
= 3 · (limx → 4 x)² - 2 · (limx → 4 x) (Sifat 5, 3, dan 8)
= 3 · (4)² - 2 · (4)
= 3 · 16 - 8 = 48 - 8 = 40
🔍 Asal Angka: Angka 16 dari 4², angka 48 dari 3 × 16, angka 8 dari 2 × 4, hasil 48 - 8 = 40.
Contoh Soal b (Slide 3): limx → 4 [√(x² + 9) / x]
Langkah Pengerjaan:
= [√(limx → 4 (x² + 9))] / [limx → 4 x] (Sifat 7 dan 9)
= √(4² + 9) / 4
= √(16 + 9) / 4 = √25 / 4 = 5 / 4 = 1,25
🔍 Asal Angka: Angka 25 dari 16 + 9 di dalam akar, ditarik akar menghasilkan 5, dibagi penyebut 4.

📌 3. Sepuluh Rumus Baku Limit Trigonometri di x → 0 (Slide 5)

1. lim (sin mx) / (nx) = m / n
2. lim (mx) / (sin nx) = m / n
3. lim (sin mx) / (sin nx) = m / n
4. lim (tan mx) / (nx) = m / n
5. lim (mx) / (tan nx) = m / n
6. lim (tan mx) / (tan nx) = m / n
7. lim (sin mx) / (tan nx) = m / n
8. lim (tan mx) / (sin nx) = m / n
9. lim (sin x) / x = 1
10. lim (tan x) / x = 1
Identitas Kunci Pengubah Kosinus (Paling Sering Digunakan di Ujian):
Kosinus tidak memiliki bentuk rasio langsung seperti sin dan tan di x → 0, sehingga WAJIB diubah menggunakan rumus sudut rangkap:
  • 1 - cos 2x = 2 sin² x
  • 1 - cos x = 2 sin²(x / 2)
  • cos 2x = cos² x - sin² x = 1 - 2 sin² x = 2 cos² x - 1

📝 BAGIAN 2: BEDAH TUNTAS SELURUH SOAL LATIHAN LIMIT ALJABAR (SLIDE 4)

Langkah matematis rinci, analisis bentuk tentu vs tak tentu, dan asal-usul angka setiap baris.

Soal 1: limx → 1 (3x + 5)

1. Analisis Bentuk: Fungsi polinomial linier yang kontinu di seluruh bilangan real. Substitusi langsung menghasilkan nilai pasti (bukan 0/0).
2. Perhitungan Rinci:
= 3(1) + 5 = 3 + 5 = 8
3. Asal Angka: Angka 3 berasal dari koefisien 3 dikalikan pendekatan x = 1, ditambah konstanta 5 menghasilkan angka 8.

Soal 2: limx → 1 [(x - 1)³ / (x - 1)]

1. Analisis Bentuk: Substitusi x = 1 menghasilkan (1 - 1)³ / (1 - 1) = 0 / 0 (Bentuk Tak Tentu).
2. Penyelesaian Aljabar:
Karena x → 1 (artinya x ≠ 1), kita dapat membagi faktor pembuat nol (x - 1):
limx → 1 [(x - 1)³ / (x - 1)] = limx → 1 (x - 1)²
Substitusikan x = 1:
= (1 - 1)² = 0² = 0
3. Asal Angka: Pangkat 3 dibagi pangkat 1 menjadi pangkat 2, yaitu (x - 1)². Saat x = 1 dimasukkan, 1 - 1 = 0, kuadrat dari 0 adalah 0. Catatan: Angka 0 adalah hasil limit yang sah.

Soal 3: limx → 2 [(x² - 7x + 10) / (x - 2)]

1. Analisis Bentuk: Substitusi x = 2 → (4 - 14 + 10) / (2 - 2) = 0 / 0 (Bentuk Tak Tentu).
2. Pemfaktoran Kuadrat Pembilang:
Cari dua bilangan yang dikali menghasilkan +10 dan dijumlahkan menghasilkan -7: yaitu -2 dan -5.
Maka: x² - 7x + 10 = (x - 2)(x - 5).
3. Eliminasi Faktor Pembuat Nol:
limx → 2 [(x - 2)(x - 5)] / (x - 2) = limx → 2 (x - 5)
Substitusikan x = 2:
= 2 - 5 = -3
4. Asal Angka: Faktor (x - 2) saling membatalkan. Tersisa (x - 5). Ketika x diganti angka 2, 2 - 5 menghasilkan -3.

Soal 4: limx → 1 [(x - 1) / (√x - 1)]

1. Analisis Bentuk: Substitusi x = 1 → (1 - 1) / (√1 - 1) = 0 / 0 (Bentuk Tak Tentu Memuat Akar).
2. Metode Perkalian Sekawan:
Kalikan pembilang dan penyebut dengan sekawan penyebut yaitu (√x + 1):
limx → 1 [(x - 1)(√x + 1)] / [(√x - 1)(√x + 1)]
Penyebut dikalikan: (√x - 1)(√x + 1) = (√x)² - 1² = x - 1.
Bentuk limit menjadi:
limx → 1 [(x - 1)(√x + 1)] / (x - 1) = limx → 1 (√x + 1)
Substitusikan x = 1:
= √1 + 1 = 1 + 1 = 2
3. Asal Angka: Faktor (x - 1) tercoret habis. Tersisa √x + 1. Nilai akar 1 adalah 1, ditambah 1 menjadi 2.

Soal 5: limx → 4 [(4x - x²) / (2 - √x)]

1. Analisis Bentuk: Substitusi x = 4 → (16 - 16) / (2 - 2) = 0 / 0.
2. Faktorkan Pembilang & Kalikan Sekawan:
Pembilang: 4x - x² = x(4 - x).
Sekawan penyebut (2 - √x) adalah (2 + √x).
Kalikan pembilang dan penyebut dengan (2 + √x):
limx → 4 [x(4 - x)(2 + √x)] / [(2 - √x)(2 + √x)]
Penyebut: (2)² - (√x)² = 4 - x.
Maka faktor (4 - x) saling membatalkan:
= limx → 4 [x · (2 + √x)]
Substitusikan x = 4:
= 4 · (2 + √4) = 4 · (2 + 2) = 4 · 4 = 16
3. Asal Angka: Angka 4 dari nilai x di luar kurung, angka 2 + 2 = 4 di dalam kurung (karena akar 4 adalah 2). Hasil kali 4 × 4 = 16.

🚀 Soal Cerita Terapan Fisika Gerak Lurus S(t) (Slide 4)

Sebuah benda bergerak sepanjang garis lurus dengan posisi terhadap waktu t (detik) dan S (meter) dengan fungsi:
S(t) = (t² + 4t - 12) / (t - 2)
a. Hitunglah limt → 2 S(t)!
Substitusi awal menghasilkan (4 + 8 - 12) / (2 - 2) = 0 / 0.
Faktorkan pembilang: cari dua bilangan yang dikali = -12 dan ditambah = +4 (yaitu +6 dan -2):
t² + 4t - 12 = (t - 2)(t + 6)
Bentuk limit:
limt → 2 [(t - 2)(t + 6)] / (t - 2) = limt → 2 (t + 6)
Substitusikan t = 2:
= 2 + 6 = 8 meter
b. Interpretasikan hasil limit tersebut!
Interpretasi Fisika: Nilai limit 8 meter mengindikasikan bahwa ketika waktu t semakin mendekati detik ke-2 (baik dari detik 1,999 maupun 2,001), posisi fisik benda mendekati tepat pada titik koordinat 8 meter dari titik awal gerak. Meskipun secara rumus matematis murni terjadi pembagian nol pada t = 2, secara kontinuitas fisik benda tersebut tidak melompat melainkan bergerak mulus melintasi posisi 8 meter.

📐 BAGIAN 3: BEDAH TUNTAS 9 SOAL LATIHAN LIMIT TRIGONOMETRI (SLIDE 8, 9, 10)

Langkah matematis detail, penggunaan identitas sudut rangkap, dan penjelasan dari mana setiap angka berasal.

Soal 1: limx → 0 [2 sin(4x) / (7 tan(7x))] (Slide 8)

1. Analisis: Substitusi x = 0 menghasilkan 0/0. Konstanta koefisien adalah 2 pada pembilang dan 7 pada penyebut.
2. Penyelesaian dengan Rumus Baku:
Tarik konstanta ke depan: = (2 / 7) · limx → 0 [sin(4x) / tan(7x)]
Berdasarkan Rumus Limit Trigonometri No. 7: limx → 0 [sin(mx) / tan(nx)] = m / n.
Dengan m = 4 dan n = 7, maka lim [sin(4x) / tan(7x)] = 4 / 7.
Kalikan seluruh pecahan:
= (2 / 7) × (4 / 7) = (2 × 4) / (7 × 7) = 8 / 49
3. Asal Angka: Angka 8 berasal dari 2 × 4 di pembilang. Angka 49 berasal dari 7 × 7 di penyebut.

Soal 2: limx → π/2 (sin x + cos x) (Slide 8)

1. Analisis: Titik limit adalah x → π/2 (90°). Fungsi sinus dan kosinus kontinu di titik ini, sehingga langsung substitusi.
2. Perhitungan Berdasarkan Tabel Sudut Istimewa:
= sin(π/2) + cos(π/2) = sin(90°) + cos(90°)
Dari tabel sudut istimewa Slide 7: sin(90°) = 1 dan cos(90°) = 0.
= 1 + 0 = 1
3. Asal Angka: Angka 1 berasal dari nilai sin(π/2) dan angka 0 berasal dari nilai cos(π/2).

Soal 3: limx → 0 [(2x² + x) / sin x] (Slide 9)

1. Analisis: Substitusi x = 0 menghasilkan (0 + 0) / 0 = 0/0.
2. Faktorkan Pembilang:
Keluarkan faktor x pada pembilang: 2x² + x = x(2x + 1).
Tulis ulang limit:
limx → 0 [x(2x + 1) / sin x] = limx → 0 [x / sin x] · limx → 0 (2x + 1)
Berdasarkan Rumus No. 2: limx → 0 [x / sin x] = 1.
Substitusikan x = 0 pada bagian kedua: 2(0) + 1 = 1.
Kalikan keduanya: 1 × 1 = 1
3. Asal Angka: Angka 1 pertama dari sifat limit x/sin x, angka 1 kedua dari 2(0) + 1.

Soal 4: limx → 0 [(tan 2x · tan 3x) / 3x²] (Slide 9)

1. Analisis: Pembilang memuat perkalian dua fungsi tangen, penyebut memuat x² dengan koefisien 3.
2. Pemisahan Komponen Pecahan:
Uraikan penyebut: 3x² = 3 · x · x.
Bentuk limit menjadi:
= (1 / 3) · limx → 0 [tan(2x) / x] · limx → 0 [tan(3x) / x]
Gunakan Rumus No. 4: lim [tan(2x) / x] = 2 dan lim [tan(3x) / x] = 3.
Kalikan seluruh bilangan:
= (1 / 3) × 2 × 3 = 6 / 3 = 2
3. Asal Angka: Angka 2 dari koefisien tan 2x, angka 3 dari koefisien tan 3x, dikalikan 1/3 menghasilkan 6/3 = 2.

Soal 5: limx → 0 [(1 - cos x) / sin x] (Slide 9)

1. Analisis: Bentuk 0/0 karena cos 0 = 1 sehingga 1 - 1 = 0, dan sin 0 = 0.
2. Menggunakan Identitas Sudut Setengah (Slide 6):
Identitas: 1 - cos x = 2 sin²(x / 2).
Identitas: sin x = 2 sin(x / 2) cos(x / 2).
Substitusikan ke limit:
limx → 0 [2 sin²(x / 2)] / [2 sin(x / 2) cos(x / 2)]
Coret 2 sin(x / 2) di atas dan di bawah:
= limx → 0 [sin(x / 2) / cos(x / 2)] = limx → 0 tan(x / 2)
Substitusikan x = 0:
= tan(0) = 0
3. Asal Angka: Pembagian sin² dengan sin menyisakan sin(x/2) di atas dan cos(x/2) di bawah (yaitu tan x/2). Nilai tangen dari 0 adalah 0.

Soal 6: limx → 0 [cos 2x / (sin x - cos x)] (Slide 10)

1. JEBAKAN KLASIK UJIAN: Uji Substitusi Langsung Terlebih Dahulu!
Pembilang: cos(2 · 0) = cos(0) = 1.
Penyebut: sin(0) - cos(0) = 0 - 1 = -1.
2. Perhitungan Langsung:
Karena penyebut bernilai -1 (BUKAN NOL), ini adalah BENTUK TENTU! Tidak perlu difaktorkan.
= 1 / (-1) = -1
3. Asal Angka: Angka 1 dari cos(0), angka -1 dari sin(0) - cos(0) = 0 - 1 = -1. Hasil bagi 1 / (-1) = -1.

Soal 7: limx → π/6 [(1 / 2) cos 12x] (Slide 10)

1. Analisis: Pendekatan ke x → π/6 (30°). Fungsi kontinu sehingga langsung substitusi.
2. Perhitungan Sudut:
Argumen sudut: 12 × (π / 6) = (12 / 6) π = 2π (360°).
Dari tabel sudut istimewa Slide 7: cos(2π) = cos(360°) = 1.
Kalikan dengan koefisien di depan:
= (1 / 2) × 1 = 1 / 2 = 0,5
3. Asal Angka: Angka 12 dibagi 6 menjadi 2π. Nilai kosinus 2π adalah 1. Dikalikan 1/2 menjadi 1/2.

Soal 8: limx → 0 [2x sin 3x / tan² 5x] (Slide 10)

1. Analisis: Bentuk 0/0. Pembilang berderajat dua (x pangkat 1 dan sin 3x), penyebut berderajat dua (tan² 5x).
2. Penguraian Komponen:
Uraikan penyebut: tan² 5x = tan 5x · tan 5x.
Bentuk limit menjadi:
= 2 · limx → 0 [x / tan 5x] · limx → 0 [sin 3x / tan 5x]
Berdasarkan Rumus No. 5: lim [x / tan 5x] = 1 / 5.
Berdasarkan Rumus No. 7: lim [sin 3x / tan 5x] = 3 / 5.
Kalikan seluruh pecahan:
= 2 × (1 / 5) × (3 / 5) = (2 × 1 × 3) / (5 × 5) = 6 / 25 = 0,24
3. Asal Angka: Angka 6 di pembilang berasal dari 2 × 1 × 3. Angka 25 di penyebut berasal dari 5 × 5.

Soal 9: limx → 0 [(1 - cos 2x) / x²] (Slide 10)

1. Analisis: Bentuk 0/0 klasik yang sering muncul di kuis dan UTS FTIK Unindra.
2. Gunakan Identitas Sudut Rangkap Kosinus (Slide 6):
Rumus: cos 2x = 1 - 2 sin² x ⇔ 1 - cos 2x = 2 sin² x.
Substitusikan ke limit:
limx → 0 [2 sin² x / x²] = 2 · limx → 0 (sin x / x)²
Karena limx → 0 (sin x / x) = 1, maka:
= 2 × (1)² = 2 × 1 = 2
3. Verifikasi dengan Dalil L'Hôpital (Turunan):
Turunan pembilang: d/dx (1 - cos 2x) = 2 sin 2x.
Turunan penyebut: d/dx (x²) = 2x.
Maka: lim [2 sin 2x / 2x] = 2 × lim [sin 2x / 2x] = 2 × 1 = 2. (Terbukti 100% konsisten!)
4. Asal Angka: Angka 2 berasal dari koefisien identitas 2 sin² x yang dikalikan dengan (1)².
