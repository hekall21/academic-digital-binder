📌 1. Definisi Intuitif & Teorema Keberadaan Limit

Secara intuitif, pernyataan limx → c f(x) = L berarti bahwa ketika nilai x bergerak mendekati bilangan c (tetapi x ≠ c), maka nilai f(x) akan bergerak mendekati nilai riil L.

  • Limit Kiri: limx → c⁻ f(x) (nilai x mendekati c dari arah kiri atau nilai yang lebih kecil dari c).
  • Limit Kanan: limx → c⁺ f(x) (nilai x mendekati c dari arah kanan atau nilai yang lebih besar dari c).
  • Syarat Mutlak Keberadaan Limit: Suatu fungsi memiliki limit di titik c jika dan hanya jika limit kiri dan limit kanannya bernilai sama:
    limx → c f(x) = L  ⇔  limx → c⁻ f(x) = limx → c⁺ f(x) = L

📌 2. Sifat-Sifat Pokok Teorema Limit Aljabar

Misalkan k adalah konstanta dan limit fungsi f(x) serta g(x) keduanya ada di x → c:

  1. Limit Konstanta: limx → c k = k
  2. Limit Fungsi Identitas: limx → c x = c
  3. Perkalian Konstanta: limx → c [k · f(x)] = k · limx → c f(x)
  4. Penjumlahan & Pengurangan: limx → c [f(x) ± g(x)] = limx → c f(x) ± limx → c g(x)
  5. Perkalian Dua Fungsi: limx → c [f(x) · g(x)] = limx → c f(x) · limx → c g(x)
  6. Pembagian Dua Fungsi: limx → c [f(x) / g(x)] = limx → c f(x) / limx → c g(x), asalkan limx → c g(x) ≠ 0.
  7. Perpangkatan & Akar: limx → c [f(x)]ⁿ = [limx → c f(x)]ⁿ

📌 3. Tiga Metode Evaluasi Limit Aljabar (Contoh Langkah demi Langkah)

Metode 1: Substitusi Langsung
Jika fungsi terdefinisi di x = c dan menghasilkan bilangan real, maka nilai tersebut adalah nilai limitnya.
Contoh: limx → 2 (3x² - 5x + 4) = 3(2)² - 5(2) + 4 = 12 - 10 + 4 = 6.

Metode 2: Pemfaktoran Aljabar (Mengatasi Bentuk 0 / 0)
Bila substitusi langsung menghasilkan 0 / 0, faktorkan pembilang dan penyebut untuk mengeliminasi pembuat nol (x - c).
Contoh: Hitunglah limx → 2 (x² - 4) / (x - 2).
Langkah penyelesaian:
1. Substitusi awal: (2² - 4) / (2 - 2) = 0 / 0 (Bentuk tak tentu).
2. Faktorkan selisih kuadrat: x² - 4 = (x - 2)(x + 2).
3. Bentuk limit menjadi: limx → 2 [(x - 2)(x + 2)] / (x - 2) = limx → 2 (x + 2).
4. Substitusi kembali nilai x = 2: 2 + 2 = 4.

Metode 3: Perkalian Sekawan Bentuk Akar
Digunakan ketika bentuk memuat selisih akar kuadrat yang menghasilkan 0 / 0.
Contoh: Hitunglah limx → 4 (x - 4) / (√x - 2).
Langkah penyelesaian:
1. Kalikan pembilang dan penyebut dengan sekawan penyebut yaitu (√x + 2):
limx → 4 [(x - 4)(√x + 2)] / [(√x - 2)(√x + 2)]
2. Perhatikan penyebut: (√x - 2)(√x + 2) = (√x)² - 2² = x - 4.
3. Bentuk disederhanakan: limx → 4 [(x - 4)(√x + 2)] / (x - 4) = limx → 4 (√x + 2).
4. Substitusi nilai x = 4: √4 + 2 = 2 + 2 = 4.

Metode 4: Limit Menuju Tak Hingga (x → ∞)
Bagi seluruh suku pembilang dan penyebut dengan variabel berpangkat tertinggi dari penyebut.
Contoh: limx → ∞ (4x² + 3x - 1) / (2x² - 5)
Bagi seluruh suku dengan x²:
= limx → ∞ (4 + 3/x - 1/x²) / (2 - 5/x²) = (4 + 0 - 0) / (2 - 0) = 4 / 2 = 2.

💡 BAGIAN 2: PENGAYAAN MATERI FIRST PRINCIPLES, INDUSTRI & JEBAKAN UTS

  • Makna 0/0: Dalam kalkulus, 0 / 0 dinamakan Indeterminate Form (Bentuk Tak Tentu), artinya limit tersebut masih menyimpan nilai riil pasti yang harus diungkap melalui operasi aljabar.
  • Trik Cepat Limit Tak Hingga: Jika derajat polinomial pembilang sama dengan penyebut (misal sama-sama berpangkat 2), nilai limit tak hingga cukup diambil dari rasio koefisien pangkat tertingginya: 4 / 2 = 2.
  • Penerapan Sistem Informasi: Konsep limit adalah fondasi analisis kompleksitas algoritma Big-O, di mana kita menganalisis batas pertumbuhan waktu komputasi saat ukuran input data (n) mendekati tak hingga.
