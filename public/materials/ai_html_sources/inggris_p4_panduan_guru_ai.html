BAB 1 Three Modalities of Future Expression in Tech Projects

Materi Slide Resmi

Professional technical communication demands clarity when stating future schedules, system predictions, and immediate operational commitments:

Future Structure Syntactic Pattern Degree of Intention & Evidence Technical Engineering Context Concrete Professional Example
Will + V1 Subject + will + Verb 1 Instant decision made at the moment of speaking, or formal contract commitment. Live incident response during on-call triage or code review standup. "I see the server error alert; I will inspect the logs immediately."
Be going to + V1 Subject + am/is/are + going to + V1 Premeditated plan, or strong projection based on visible real-time empirical evidence. Sprint roadmap milestones or telemetry dashboards warning of impending limits. "Look at the memory graph reaching 98%; the container is going to run out of memory!"
Present Continuous for Future Subject + am/is/are + V-ing Fixed arrangement with external stakeholders at a confirmed future time slot. Maintenance downtime windows, client feature demos, cloud migration schedules. "Our DevOps team is migrating the database to AWS RDS next Saturday at midnight."

BAB 2 Modal Auxiliaries for System Requirements (RFC 2119 Standard)

Materi Slide Resmi

In standard engineering documentation (such as IETF RFCs and ISO software specifications), modal auxiliaries carry strictly defined legal meanings:

RFC Keyword Modal Verb Architectural Requirement Level System Specification Example
MUST / REQUIRED must / have to Absolute requirement; violation breaks compatibility or security. "All passwords must be hashed using bcrypt with work factor ≥ 12."
SHOULD / RECOMMENDED should / ought to Strong recommendation; valid reasons may exist in particular cases to ignore it, but full implications must be weighed. "The backend API should implement rate-limiting on login endpoints."
MAY / OPTIONAL may / can Truly optional feature; implementations must interoperate whether present or not. "The client application may cache static assets in localStorage for offline access."
